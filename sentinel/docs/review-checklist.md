# Manual design review — launch only when the user chooses

No application was launched during development. Automated template checks do not certify layout.

1. Open the offline preview; verify SIMULATION labelling and paused initial state.
2. Visit every navigation item at normal window size and a narrow viewport. Check for clipped tables, readable text and focus outlines.
3. Use Ctrl+K, search ORBIT, sort/filter discovery, toggle saved tokens and inspect a token.
4. Review and confirm a £2 practice purchase. Check balance, fees and holdings. Sell half the quantity. Export CSV and compare ledger totals.
5. Test invalid spend, allocation limits and insufficient balance. Enable the failed-fill scenario if desired; every fourth attempted fill fails without a charge.
6. Press Test alert. Move popup corners in settings. Acknowledge/dismiss; refresh and verify the centre retains history. Check the seeded ECHO expired +80% example.
7. Set quiet hours or liquidity/category filters and confirm suppressed popups still leave an alert record.
8. Change theme, accent HEX/colour wheel, profit/loss colours, glass, corners, density and motion. Verify popup blur is clearly page-content blur only.
9. Add/remove keywords and account preferences. Filter/search fictional posts. Verify all sources remain disconnected.
10. Send scripted assistant questions; create/search conversations. Confirm there is no implication a model or live research service ran.
11. Export backup, change a setting, restore with confirmation and verify balances/history. Test reset only after saving a backup.
12. Optionally play simulation and verify synthetic chart changes. Hiding the tab stops simulation updates. Disable sound before testing if desired.

Known incomplete platform work: native desktop host/acrylic, SQLite, installer, real providers, Windows DND/fullscreen/monitor handling, startup/tray, signed updates, cloud sync and full realistic paper execution. No live integrations may start until explicit design approval. Visual revisions can continue without approving integrations.
